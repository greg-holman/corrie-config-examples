# Ghost publishing

Run self-hosted Ghost with its settings from Corrie Config: exact names such as database__connection__host, the official image with curl and the launcher added, database and mail passwords kept out. Tested example.

The full walkthrough, with the commands to run and what you should see, is in the guide: https://config.corrie.io/docs/ghost

Files in this folder:

- `Dockerfile`
- `compose.yaml`

To try it you need a Corrie Config key for an environment. You can make one on the free plan at https://config.corrie.io/signup?ref=config-examples
