# Directus headless CMS

Run self-hosted Directus with its settings from Corrie Config: the official image with curl and the launcher added, SECRET and the admin password kept out, and Directus restarted within a minute of a save. Tested example.

The full walkthrough, with the commands to run and what you should see, is in the guide: https://config.corrie.io/docs/directus

Files in this folder:

- `Dockerfile`
- `compose.yaml`

To try it you need a Corrie Config key for an environment. You can make one on the free plan at https://config.corrie.io/signup?ref=config-examples
