# Vite, React and static frontends

Build a Vite app (React, Vue, Svelte or plain JavaScript) with its settings from Corrie Config: which settings end up in the built files, how to build with the launcher and when to build again. Complete, tested example.

The full walkthrough, with the commands to run and what you should see, is in the guide: https://config.corrie.io/docs/vite

Files in this folder:

- `index.html`
- `package.json`
- `src/main.js`
- `vite.config.js`

To try it you need a Corrie Config key for an environment. You can make one on the free plan at https://config.corrie.io/signup?ref=config-examples
