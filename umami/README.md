# Umami analytics

Run self-hosted Umami with its settings from Corrie Config: the official image with the launcher added, the database password and APP_SECRET kept out, and Umami restarted within a minute of a save. Tested example.

The full walkthrough, with the commands to run and what you should see, is in the guide: https://config.corrie.io/docs/umami

Files in this folder:

- `Dockerfile`
- `compose.yaml`

To try it you need a Corrie Config key for an environment. You can make one on the free plan at https://config.corrie.io/signup?ref=config-examples
