# Ruby on Rails

Run a Rails app under Puma with its settings from Corrie Config: read them in an initializer, run migrations and the server through the launcher and restart within a minute of a save. Complete, tested example.

The full walkthrough, with the commands to run and what you should see, is in the guide: https://config.corrie.io/docs/rails

Files in this folder:

- `app/controllers/settings_controller.rb`
- `config/initializers/example.rb`
- `config/routes.rb`

To try it you need a Corrie Config key for an environment. You can make one on the free plan at https://config.corrie.io/signup?ref=config-examples
