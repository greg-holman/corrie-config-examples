# .NET and ASP.NET Core

Run an ASP.NET Core app with its settings from Corrie Config: read them through builder.Configuration, use __ for configuration sections and restart within a minute of a save. Complete, tested example.

The full walkthrough, with the commands to run and what you should see, is in the guide: https://config.corrie.io/docs/dotnet

Files in this folder:

- `ConfigExample.csproj`
- `Program.cs`

To try it you need a Corrie Config key for an environment. You can make one on the free plan at https://config.corrie.io/signup?ref=config-examples
