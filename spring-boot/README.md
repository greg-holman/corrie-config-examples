# Java and Spring Boot

Run a Spring Boot app with its settings from Corrie Config: bind them to a validated @ConfigurationProperties record, run the jar through the launcher and restart within a minute of a save. Complete, tested example.

The full walkthrough, with the commands to run and what you should see, is in the guide: https://config.corrie.io/docs/spring-boot

Files in this folder:

- `pom.xml`
- `src/main/java/com/example/config/ConfigExampleApplication.java`
- `src/main/resources/application.properties`

To try it you need a Corrie Config key for an environment. You can make one on the free plan at https://config.corrie.io/signup?ref=config-examples
