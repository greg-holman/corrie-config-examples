# GitHub Actions

Load an environment's settings from Corrie Config in a GitHub Actions workflow, keep the key in a repository secret, and fail the job when a setting is missing. Complete, tested example.

The full walkthrough, with the commands to run and what you should see, is in the guide: https://config.corrie.io/docs/github-actions

Files in this folder:

- `check_settings.py`
- `corrie-config.yml`

To try it you need a Corrie Config key for an environment. You can make one on the free plan at https://config.corrie.io/signup?ref=config-examples
