# Python and FastAPI

Run a FastAPI app under Uvicorn with its settings from Corrie Config, and restart it automatically within a minute of a save. Complete, tested example.

The full walkthrough, with the commands to run and what you should see, is in the guide: https://config.corrie.io/docs/python-fastapi

Files in this folder:

- `main.py`
- `requirements.txt`

To try it you need a Corrie Config key for an environment. You can make one on the free plan at https://config.corrie.io/signup?ref=config-examples
