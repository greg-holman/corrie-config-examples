# Next.js

Run a Next.js app with its settings from Corrie Config: server code reads them at request time under next start, the app restarts within a minute of a save, and NEXT_PUBLIC_ settings load at build time. Complete, tested example.

The full walkthrough, with the commands to run and what you should see, is in the guide: https://config.corrie.io/docs/nextjs

Files in this folder:

- `app/layout.js`
- `app/page.js`
- `package.json`

To try it you need a Corrie Config key for an environment. You can make one on the free plan at https://config.corrie.io/signup?ref=config-examples
