# Node.js and Express

Load an Express app's settings from Corrie Config with the launcher, and restart it automatically within a minute of a save. Complete, tested example.

The full walkthrough, with the commands to run and what you should see, is in the guide: https://config.corrie.io/docs/node-express

Files in this folder:

- `package.json`
- `server.js`

To try it you need a Corrie Config key for an environment. You can make one on the free plan at https://config.corrie.io/signup?ref=config-examples
