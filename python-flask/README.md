# Python and Flask

Load a Flask app's settings from Corrie Config with the launcher. Complete, tested example.

The full walkthrough, with the commands to run and what you should see, is in the guide: https://config.corrie.io/docs/python-flask

Files in this folder:

- `app.py`
- `requirements.txt`

To try it you need a Corrie Config key for an environment. You can make one on the free plan at https://config.corrie.io/signup?ref=config-examples
