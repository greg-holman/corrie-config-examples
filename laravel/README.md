# PHP and Laravel

Run a Laravel app under php-fpm with its settings from Corrie Config: read them in a config file, rebuild the config cache on each start and restart within a minute of a save. Complete, tested example.

The full walkthrough, with the commands to run and what you should see, is in the guide: https://config.corrie.io/docs/laravel

Files in this folder:

- `config/example.php`
- `routes/web.php`
- `zzz-corrie.conf`

To try it you need a Corrie Config key for an environment. You can make one on the free plan at https://config.corrie.io/signup?ref=config-examples
